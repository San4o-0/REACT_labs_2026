# ЛР-10. Організація структури папок та архітектура застосунку

Стартовий проєкт лабораторної роботи № 10 курсу «Розробка вебзастосунків на
React»: кавова крамниця з трьох сторінок, яка виросла зі сторінки кави
ЛР-8. Інструкція:
https://denysmatsevych.github.io/web-development-2026/react/labs/lab-10/

Застосунок уже працює. У цій роботі ви не пишете нових функцій, а
переносите ті самі файли з однієї структури папок в іншу: за типом файлів
(як зараз), за маршрутами, за функціональністю й Feature-Sliced Design. За
додатковий бал кошик стає локальним пакетом за Надією Макаревич. Готові
тести стежать, щоб застосунок працював після кожного переміщення, а
dependency-cruiser і Steiger перевіряють правила кожної структури. У
`STRUCTURES.md` ви записуєте, де живе кошик у кожній структурі, і обираєте
структуру для п'яти проєктів.

## Сторінки

- `#/` — каталог: вісім сортів кави, ♡ і «Додати в кошик» на кожній
  картці;
- `#/beans/<id>` — сторінка сорту зі сторінки ЛР-8: картка товару й
  вкладки «Заварювання», «Відгуки (N)» і «Схожі товари»;
- `#/cart` — кошик: кількість, сума, «Видалити».

Шапка на кожній сторінці веде в каталог і показує «Кошик (N)».

## Що вже є

- код ЛР-8, уже готовий: `Tabs` з ролями й клавіатурою за APG, HOC
  `withAnalytics`, таймери, відгуки й «Схожі товари»;
- маршрутизатор на адресі після `#`: хук `useRoute`, адреси сторінок у
  `src/utils/paths.js` і компонент `Link`;
- кошик: сховище `src/store/cartStore.js` у `localStorage` і хук
  `useCart`;
- тести Vitest і React Testing Library в `tests/`. Застосунок вони
  імпортують як `#app` (поле `imports` у `package.json`), тому переміщення
  файлів у `src/` їх не ламає. Файли в `tests/` не змінюйте;
- `.dependency-cruiser.cjs` — правила всіх структур роботи. Його теж не
  змінюйте;
- `jsconfig.json` — з ним редактор оновлює імпорти в усіх файлах, коли
  ви переміщуєте файл. Не видаляйте його;
- `STRUCTURES.md` — дві таблиці, які ви заповните;
- стилі всього застосунку в `src/index.css`.

## Команди

`npm install` виконуйте в корені репозиторію `react-labs`, решту — у теці
`lab-10/`:

- `npm run dev`: dev-сервер на http://localhost:5173
- `npm test`: тести в режимі спостереження; `q` — вихід
- `npx vitest run`: усі тести один раз
- `npm run lint`: ESLint
- `npm run check:deps`: правила структур (dependency-cruiser)
- `npm run check:fsd`: правила Feature-Sliced Design (Steiger), з §4.6
- `npm run format:check`: перевірка форматування Prettier
- `npm run build`: production-збірка в `dist/`
